Meal Distribution System: Scalable Logistics & Payment Infrastructure

Live
2026 · Database Systems Coursework - Spring'26

Full-stack institutional catering and logistics orchestration platform built with Next.js App Router, Neon Serverless PostgreSQL, and Tailwind CSS. Features a 3NF relational architecture powering four role-segregated portals, a multi-stage kitchen order state machine, simulated bKash/Card payment processing, customer item reviews, and an instant zero-friction demo role switcher.

  • Serverless PostgreSQL & 3NF Relational Layer: Backed by Neon Serverless PostgreSQL with pooled connections, normalized 3NF schemas (Order, Order_History, Payment), idempotent migrations, and automatic casing normalization for resilient serverless execution.
  • Four-Tier RBAC & Lifecycle State Machine: Enforces role governance across Customer, Kitchen, Delivery, and Admin domains using HTTP-only session cookies and proxy middleware. Tracks order progression through strict chronological stages (Pending → Kitchen_Accepted → Cooking_Done → Dispatched → Delivered).
  • Instant Demo Switcher & Commerce Engine: Incorporates a floating, zero-logout role switcher for recruiter evaluations, a reactive menu catalog with cart state management, simulated digital checkout, and verified post-delivery star-rating feedback loops.

Medical SOS: Real-Time Emergency Dispatch & Telemedicine System

Live
2025 · Database Systems Coursework - Fall'25

Full-stack emergency healthcare, telemedicine, and pharmacy management platform built with Next.js App Router, TypeScript, Prisma, Neon Serverless PostgreSQL, and Tailwind CSS. Features one-tap emergency SOS dispatch with GPS fallback, digital doctor consultation queues with prescription issuance, multi-item pharmacy ordering with rider fulfillment, and an instant live database role switcher.

  • Relational PostgreSQL Architecture & Connection Resiliency: Backed by Neon Serverless PostgreSQL and Prisma ORM with connection pooling, dual serverless binary targets (native, rhel-openssl-3.0.x), and strict foreign key relations modeling emergency calls, appointments, multi-item orders, and user health cards.
  • Five-Role RBAC & Lifecycle State Machine: Enforces deterministic role routing across Patient, Doctor, Driver, Delivery, and Admin domains using Next.js Server Actions, tracking chronological status progressions from SOS dispatch to doctor prescription completion and doorstep pharmacy package delivery.
  • Live Demo Switcher & Graceful Geolocation: Features an on-screen instant database role mutator and one-click account switcher for viva evaluations, paired with automated central Dhaka GPS fallback (23.8103, 90.4125) ensuring uninterrupted distress signaling when browser geolocation is unavailable.
